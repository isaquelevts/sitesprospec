# Curso Big Bang — Astronomia com Sérgio Sacani

Landing page do curso (página estática, sem build). GSAP 3.13 (ScrollTrigger, SplitText, CustomEase) + Lenis via CDN.

- `index.html` · estrutura · `styles.css` / `finale.css` · estilos · `tokens.css` · cores e tipos
- `loader.js` · loader do foguete · `main.js` · rolagem suave, hero, transições e seções · `programa.js` · conteúdo programático · `finale.js` · missões, oferta, depoimentos, FAQ, rodapé
- `assets/` · imagens

## Fonte

O projeto usa a **Articulat CF** (licenciada), que **não está neste repositório**. Sem ela, a página usa a **Geist** como reserva.
Para usar a original, coloque `ArticulatCF-Regular.otf` e `ArticulatCF-DemiBold.otf` em `assets/fonts/`
(o `@font-face` em `tokens.css` já aponta para esses nomes).

## Depoimentos

Os vídeos do YouTube estão em `data-yt` nos botões `.voice` do `index.html`.
